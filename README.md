# 🧬 Minicurso: Introdução a Python para Dados Biológicos

Bem-vindo(a) ao repositório do minicurso **Introdução a Python para Dados Biológicos**! Este espaço foi criado para guardar todo o material didático, códigos de exemplo e exercícios práticos das nossas aulas.

O objetivo deste curso é ensinar os fundamentos da programação em Python para estudantes e pesquisadores das áreas biológicas, focando em aplicações práticas do dia a dia da bioinformática.

---

## 🚀 O que vamos aprender?

O curso está dividido em módulos práticos:

*   **Módulo 1: Primeiros Passos com Python**
    *   Configuração do ambiente (Google Colab / Anaconda)
    *   Variáveis, tipos de dados (números e textos) e operações básicas
*   **Módulo 2: Estruturas de Dados e Controle**
    *   Listas, tuplas e dicionários
    *   Estruturas de decisão (`if`, `elif`, `else`)
    *   Estruturas de repetição (`for` e `while`)
*   **Módulo 3: Manipulação de Arquivos Biológicos**
    *   Como abrir e ler arquivos de texto
    *   Manipulação de sequências (contar nucleotídeos, transcrição e tradução)
    *   Introdução à leitura de arquivos FASTA e FASTQ
*   **Módulo 4: Introdução à Análise de Dados**
    *   Primeiros passos com a biblioteca `pandas`
    *   Como ler tabelas de expressão gênica e metadados

---

## 🛠️ Como usar este repositório

1.  **Acesse o material:** Os códigos de cada aula estão na pasta `/notebooks` (se houver) ou listados na tabela de aulas.
2.  **Pratique:** Abra os arquivos `.ipynb` diretamente no **Google Colab** para rodar o código sem precisar instalar nada no seu computador.
3.  **Dúvidas:** Se tiver algum problema com os códigos, abra uma *Issue* aqui no GitHub.

---

## 📋 Pré-requisitos

Não é necessário nenhum conhecimento prévio em programação! O curso começa do zero. 

Apenas recomendamos que você tenha uma conta no **Google** para conseguir usar o Google Colab durante as práticas.
